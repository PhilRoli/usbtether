# usbtether

A trimmed, hardened fork of [rtether](https://github.com/nkazbekov/rtether) (MIT OR Apache-2.0): a macOS userspace RNDIS USB-tethering daemon (`usbtetherd`). It also builds on the ideas of erg-tether. Unlike upstream it only talks to phones on an approved-phone allowlist.

Status: under construction.
